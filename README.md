# 『オントロジー開発 101：はじめてのオントロジー作成ガイド』日本語訳

オントロジーとは何か、なぜ開発するのか、クラス階層やプロパティをどう設計するかを、ワインと料理の例で解説した入門文書――執筆当時スタンフォード大学に在籍していた Natalya F. Noy と Deborah L. McGuinness による "Ontology Development 101: A Guide to Creating Your First Ontology" の日本語訳です。  
（著者の許可を得て公開していますが、非公式の翻訳です。原文: https://protege.stanford.edu/publications/ontology_development/ontology101-noy-mcguinness.html / 翻訳：林 邦行）  
訳の間違いや分かりにくい箇所を見つけたら、[Issue](https://github.com/khayashi4337/ontology101-ja/issues) で翻訳者にお知らせください（章の番号と該当する文を添えてもらえると助かります）。
